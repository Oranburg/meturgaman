# Companion works

Some works are studied in pairs: one carries the ruling and the other the
reasoning, and reading the first without the second misses what its author
thought the law was for. This file names those pairs. It is a document, not
code, for the same reason the romanization tables are documents: a pairing
buried in code is a pairing nobody checks or extends.

What this file does and does not claim. It names which companion work is
worth opening alongside a given work, and why. It does not claim to know
which passage of the companion bears on which passage of the text; that
connection comes from Sefaria's link graph at run time, passage by passage,
so nothing here is ever the source of a citation. Where the graph records no
companion passage, the tool says so instead of guessing, because the graph
is genuinely sparse: of the Mishneh Torah passages sampled when this file
was written, Foundations of the Torah 2:2 and Prayer 1:1 carry Guide links
and Repentance 5:5 carries none.

| When studying | Also open | Why |
|---|---|---|
| Mishneh Torah | Guide for the Perplexed | The same author, divided by design: the code states the law and the Guide argues the ideas underneath it. Pairing them is the standing convention of this project's study files. |
| Shulchan Arukh | Beit Yosef | Karo's ruling with Karo's reasoning: the Beit Yosef is his own survey of the sources and arguments his code then compresses into law. |
| Tur | Beit Yosef | The Beit Yosef is written on the Tur, siman by siman. |

Extending this table: every row needs a reason a reader can check, and the
companion's name must match the index title Sefaria uses, because that is
the string the link graph is filtered by.
